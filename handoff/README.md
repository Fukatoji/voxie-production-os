# Handoff

Use this directory for compact, text-based handoff records between ChatGPT, Codex, and production operators.

A handoff should state:
- production ID and version
- current status
- authoritative inputs
- approved/locked outputs
- unresolved blockers
- next permitted action
- required approval or spend gate

Do not store large media here. Link to the authoritative external asset location through manifests or stable asset IDs.
